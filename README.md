# ViVideoYouTube

Мини-приложение для загрузки видео и шортсов на YouTube.

**Стек:** Python 3.14 · PyQt6 · YouTube Data API v3 · OAuth2

## Возможности

- 🌑 Тёмная тема (единый QSS-стиль, акцент — фирменный красный YouTube).
- Четыре вкладки: **«🎬 Видео»**, **«⚡ Шортсы»**, **«💬 Субтитры»** и **«🎵 Убрать музыку»**.
- Простая загрузка: **нажал кнопку → выбрал файл** → название подставится из имени.
- **Авто-шаблон для аниме-шортсов**: введи `название аниме` и `озвучку` — приложение
  само составит название (`«Название» — нарезка | Озвучка`), красивое описание
  (с сайтом `vilibrity.ru` и телеграмом) и теги с автодублированием на русский/английский.
  Всё остаётся редактируемым перед загрузкой.
- **Вкладка «Субтитры»**: выбираешь видео → показывается примерное время работы →
  распознаётся речь → встраиваются karaoke-субтитры по центру (текущее слово — жёлтым,
  остальные — белым). Модель, язык и шрифт настраиваются.
- **🎵 Вкладка «Убрать музыку»**: выбираешь видео → Demucs убирает музыку/саундтрек,
  оставляя голос/озвучку, результат — `..._vocals.mp4`. Снижает риск бана за авторские
  права на музыку. Тот же чекбокс есть и в загрузке (Видео/Шортсы).
- Поля: название, описание, теги, категория, видимость (приватно/не перечислено/публично),
  превью (thumbnail), «для детей».
- Прогресс загрузки в фоне (не блокирует UI) + итоговая ссылка на видео.
- OAuth2-авторизация через `client_secret_*.json`, refresh-токен сохраняется в `token.json`.
- Корректное закрытие по крестику: фоновые потоки останавливаются, окно не зависает.

## Установка

```bash
# Виртуальное окружение уже создано (venv), просто ставим зависимости:
venv/bin/pip install -r requirements.txt

# (опционально) автоматическое определение длительности шортсов через ffprobe:
#   apt install ffmpeg

# ⚙️ Конфигурация: создайте свой .env из шаблона и впишите реальные ключи
#    (получаются в Google Cloud Console → APIs & Services → Credentials)
cp .env.example .env
```

> **Важно:** после клонирования репозитория обязательно положите рядом файл
> `client_secret_<client_id>.json` (скачивается в Google Cloud Console →
> раздел «Credentials» → Create OAuth client ID → Desktop app) — без него не
> заработает OAuth-авторизация. Эти файлы и `.env` не хранятся в git (см.
> `.gitignore`) — их нужно держать локально и никогда не публиковать.

## Запуск

```bash
venv/bin/python main.py
```

## Auto Caption (субтитры в видео)

Распознаёт речь и **красиво встраивает karaoke-субтитры прямо в видео**:
- слово, произносимое **сейчас** — **жёлтым**,
- остальные слова строки — **белыми**,
- текст **по центру**, с обводкой; длинные строки автоматически разбиваются,
  чтобы не вылезать за края.

Доступен двумя способами:

**1. В приложении** — вкладка **«💬 Субтитры»**: выбери видео → увидишь примерное
время работы → «Создать субтитры». Модель, язык и размер шрифта настраиваются.

**2. Отдельным скриптом** `subtitle_tool.py`:

```bash
# все зависимости (включая faster-whisper, onnxruntime, demucs) ставятся одной командой:
venv/bin/pip install -r requirements.txt

# базово
venv/bin/python subtitle_tool.py my_video.mp4

# точнее + русский
venv/bin/python subtitle_tool.py my_video.mp4 --model small --lang ru --keep
```

Параметры:

| Флаг | Описание |
|------|----------|
| `--model {tiny,base,small,medium}` | Точность/скорость. `small` — хороший баланс |
| `--lang ru/en/ja…` | Язык (по умолчанию ru; пустое = автоопределение) |
| `-o ФАЙЛ` | Выходной файл (по умолчанию `<видео>_captioned.mp4`) |
| `--font / --font-size` | Шрифт и размер субтитров |
| `--keep` | Сохранить промежуточный `subs.ass` рядом с результатом |

Точность: используется `word_timestamps=True` — каждое слово получает точный
таймкод, поэтому жёлтая подсветка совпадает со звуком. Модель скачивается один
раз при первом запуске. Нужен установленный `ffmpeg`.

## Удаление музыки (Demucs)

Есть вкладка **«🎵 Убрать музыку»** и чекбокс **«Убрать музыку (оставить голос
и эффекты)»** во вкладках «Видео»/«Шортсы». Видео прогоняется через **Demucs
(`htdemucs_6s`)** — разделение на 6 стемов:

- **остаются**: `vocals` (голос/озвучка), `other` (эффекты: шаги, шелест, скрипы),
  `drums` (ударные/стуки) — чтобы сохранить звуковые эффекты;
- **убираются**: `bass`, `guitar`, `piano` — явная музыка.

Баланс настроен так, чтобы максимально сохранять эффекты, даже если лёгкий
музыкальный фон останется. Это заметно снижает риск бана за авторские права
на музыку/саундтрек.

Требуется: `demucs` + `torch` (ставятся через `venv/bin/pip install -r requirements.txt`). У тебя есть
RTX 3060 — демucs автоматически использует CUDA (быстро); при желании можно
собрать и CUDA-версию torch через `pip install torch torchaudio --index-url
https://download.pytorch.org/whl/cu126`.

## Авторизация

Перед первой загрузкой нажмите **Приложение → 🔑 Авторизация в YouTube**.
Откроется браузер — подтвердите доступ. Токен сохранится в `token.json`
(создаётся автоматически в корне проекта) и не будет запрошен повторно.

## Файлы конфигурации

| Файл | Назначение |
|------|-----------|
| `.env.example` | Шаблон настроек (коммитится, без реальных ключей) |
| `.env` | API-ключ, Client ID/Secret, пути, скоупы (НЕ коммитится) |
| `client_secret_*.json` | OAuth-клиент (installed app) для авторизации (НЕ коммитится) |
| `token.json` | Создаётся после первой авторизации (НЕ коммитится) |

> ⚠️ Файлы `.env`, `client_secret_*.json` и `token.json` исключены через
> `.gitignore`. Храните их только локально и никогда не публикуйте и не
> отправляйте третьим лицам: `client_secret` — это ключ доступа к вашему
> Google Cloud-проекту, а `token.json` — реальный авторизационный токен.

